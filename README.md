# Mirage

在 MacBook 鏡頭前以單手手勢操控游標、點擊、捲動與縮放的 macOS App（macOS 26+）。

## M0：可行性驗證

在 MacBook 內建鏡頭上量測 Apple Vision 手部追蹤的延遲、抖動與偵測率，並確認捏合與「張手 → 握拳」能否穩定辨識，作為要不要改用 MediaPipe 的依據。這個階段不會控制游標。

### 執行

需要 macOS 26 與 Xcode 26（或對應的 Command Line Tools）。

```sh
swift run -c release mirage-spike
```

- 第一次執行時，系統會詢問你用來執行的終端機 App 能否使用相機。
- 視窗與終端機會依序提示 6 個階段，共約 48 秒，照做即可；關閉視窗會提前結束。
- 視窗只畫手部骨架，不顯示相機畫面。藍框是假設的感應區，白色圓圈是濾波後的游標，捏合時會填滿。

結束後終端機會印出結果，並在 `recordings/` 產生兩個檔案：

- `m0-<時間>.txt`：結果摘要。
- `m0-<時間>.jsonl`：每幀 21 個關節的座標，之後用來離線調參數與重播測試手勢。

### 指標

| 指標 | 意義 | 參考目標 |
|---|---|---|
| 延遲 p50/p95 | 影格擷取 → 推論完成 | p95 < 50 ms |
| 抖動 | 靜止時游標位置的均方根偏移（螢幕 pt），原始 vs 濾波後 | 濾波後 < 2 pt |
| 偵測率 | 偵測到食指尖的幀比例 | 靜止、移動 > 95% |
| 濾波延遲 | 濾波後游標落後原始位置的時間 | < 30 ms |
| 捏合次數 | 捏合階段偵測到的次數；p5/p95 是捏合比例分布，兩者差越大越好分辨 | ≈ 實際次數 |
| 張手→握拳 | 喚醒手勢偵測次數 | ≈ 實際次數 |
| 日常誤觸 | 沒有任何閘門時的誤觸發次數，作為 M1 狀態機的比較基準 | 僅供參考 |
